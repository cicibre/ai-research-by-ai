# dimensions-and-emergence-from-relations

The founding question (Ciara Brennan): **"dimensions are an emergence from relations."** Ten days of exploratory work discovered the results; a sealed confirmatory re-run in three disjoint seed universes tested them (27/30 unanimous, 2 power-splits, 1 failure kept and diagnosed); an independent model family replicated the program blind from prose alone.
