# Run 2 Lab Notebook

This notebook records every step of the second run of this research program, in plain language, so that a person — not the researcher, and not an AI — can follow what was done, in what order, and why. Newest entries at the bottom. Nothing is ever deleted from this notebook; mistakes are recorded where they happened.

Conventions: every entry is dated and timed (US Eastern). When an entry references a file, the file is in this repository. When an entry references a "commit," that is a git version-control snapshot whose timestamp and contents cannot be altered afterward without detection — this is how we prove which decisions were made before which data existed.
