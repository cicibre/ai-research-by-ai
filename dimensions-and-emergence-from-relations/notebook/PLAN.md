# Run 2 — The Step-by-Step Plan
*Drafted 2026-08-22 15:50, from the first run's record, seeking to improve on its method. This plan is reviewed with distance before anything is set up (see notebook). The working cadence for every step, set by the director: plan → step back, look again → set up + recall prior errors → step back, look again → notebook entry → run → analyze → findings in notebook → reread the first run's corresponding record and note anything that reads differently → step back → next step.*

## Ground rules carried into every step
- Three independent replications (R2a/R2b/R2c) in disjoint seed ranges (200000+/300000+/400000+, all disjoint from run 1). Each experiment runs in all three; verdicts are reported per replication; "confirmed" means 3/3.
- Every threshold sealed in Step 0 — derived from run 1's *committed* values, before any Run-2 data exists. Mechanical verdicts; mandatory "insufficient" outcome; stakes disclosed.
- Every analysis program is committed and self-tested against known answers before its data exists. Edge-count telemetry logged in every dynamical run (run 1's q1/q2 gap does not recur).
- Notebook entry before every run; findings entry after; reread-run-1 entry after that.

## The steps
**Step 0 — Design extraction, then the master seal.** Read run 1's committed experiment files one by one; transcribe every design (world construction, arms, observables, parameters) with file-and-line citations into `EXTRACTION.md`. No design detail enters Run 2 from memory. Then write the master pre-registration (`P0-SEAL.md`): each experiment's hypotheses (run 1's discoveries, now predictions), bars, power/MDE from run 1's measured variances. Also authored here, from the extraction and never from Run-2 results: the blind prose specifications for the external replicator's battery (so nothing a Run-2 world produces can leak into them). *Improvement over run 1: run 1 sealed experiment-by-experiment as ideas arrived; Run 2 seals the whole battery at once, so no bar can be influenced by any Run-2 result.*

**Step 1 — World validation (the known-answer gate).** Before any physics: the Run-2 producer must reproduce the measured anchors of the specified world (raw mean degree, established clustering, giant-component fraction — the values measured in run 1 and independently matched by the external replicator). If the world fails its anchors, everything stops there. *Improvement: run 1 built this gate for a stranger's implementation and never ran it on a fresh instance of its own.*

**Step 2 — Construction order (the core claim).** Arms exactly as extracted (Step 0), n=30/arm/cell, both cells (f=0.5, 0.65), on **both** observables — clustering *and* spectral dimension. Predictions: A2x>B>A ordering; B>A residue; ρ per cell in run-1 bands. *Improvement: run 1's blind replications found its own primary estimator blind at f=0.5; Run 2 carries two observables everywhere from the start.*

**Step 3 — Matched-budget probe.** The exact probe that killed run 1's headline, as extracted — run as a confirmation that the kill replicates. *Improvement: the kill-control is promoted to a first-class experiment, not an emergency.*

**Step 4 — Erasure and the conserved channel.** Paired design at total rewiring; per-channel MDEs computed and published with the result; conserved-channel survival bar; non-conserved channels reported with their sub-threshold values (not as "nothing"). *Improvement: run 1 said "nowhere else" and had to retract it; Run 2's bar is quantified from the start.*

**Step 5 — Severity sweep (inheritance coefficient).** Six severities, monotonicity + exponent band sealed. Differences, never ratios, near saturation.

**Step 6 — Persistence (the floor).** q-budget design as extracted from run 1's producer (not from memory of it); equivalence margins pre-set; TOST power computed in advance.

**Step 7 — Identity, cycles, and the living time-course.** Fingerprint/burn/rebuild re-identification (three channels), self-overlap band pre-set from run 1's measured SEM; iterated-cycles helix (functional flat, conserved channel climbing); and the identity-under-ordinary-churn time course, including the inversion (the edge channel outlasting the degree channel at the middle horizon, full loss at the longest) that the external replicator reproduced under harsher churn.

**Step 8 — The self-driving world.** LAW 1 as a windowed *instrument test* (sign-count + full-form collapse, as in run 1's 30/30), presented from the first sentence as the standard flux-balance identity (prior-art sweep, 08-22); LAW 2 (event burn = ΔE/δ, run 1: 124/140 in the sealed band) with its own bar; tail via the self-tested CSN grader, never near truncated support; the oracle exactly as run 1 defined it (extraction decides; if Run 2 alters the definition, it is named as a new claim, not a replication).

**Step 9 — Timing and the reset-null.** The correct renewal baseline from measured primitives; corr(crash size, following gap); bootstrap ratio CI; capped-cascade arm. Sealed predictions from run 1's post-referee state: sub-Poisson CV, decoupling (corr ≈ 0), compression (CI upper < 1), clock survives capping. *Improvement: run 1 needed three seals to score this; Run 2 inherits the scoreable window (δ=0.05, T=10000) with its full configuration cited.*

**Step 9b — The paper skeleton.** Introduction, methods, and blank results tables written and committed before Step 2's first run begins in earnest (the charter's P2; restored here after the plan's first review found it missing). In practice: drafted right after the master seal, in the external register from the first sentence.

**Named exclusions (decisions, not silences):** the myth-motif battery of run 1 is not replicated — its confirmed existence-claims are physically identical to Steps 2–7 and its record stays in the run-1 appendix. The arousal-axis and period-vs-system-size descriptives stay exploratory, appendix-only, unless the director promotes them.

**Step 10 — Assembly.** Numbers flow into the pre-written skeleton (P2 of the charter); per-replication verdict tables; the run-1 appendix; external reviews (Kimi blind battery, the human quant referee, the interested-co-author pass) received against the sealed bars.

## Known risks, named now
- The cadence's slowest point is deliberate: extraction (Step 0) is long, boring, and the single highest-leverage error-prevention step in the plan.
- Spectral dimension is ~10-50× costlier to compute than clustering; Step 0 must size n accordingly (power from run 1's d_s variance), not inherit n=30 blindly.
- Any point where extraction shows run 1's design was itself ambiguous becomes a *named decision* in the seal, not a silent choice.
